BastionTestSandbox

DEPRECATED: This module has moved to the Bastion framework package. Add bastion as a dependency in your forge.toml and import it from there. This stdlib copy will be removed in a future march release.

BastionTestSandbox: isolated request sandboxes for controller tests.

Each sandbox gets a unique namespace so concurrent tests never share Vault data or PubSub subscriptions. The sandbox lifecycle is:

let env = BastionTestSandbox.checkout("my_app") let conn = BastionTestSandbox.build_conn(env, :get, "/users") -- … run your pipeline … BastionTestSandbox.release(env)

Vault isolation is achieved by prefixing every key with the sandbox nonce. PubSub isolation is achieved by using a unique pubsub_name per sandbox.

The SandboxEnv record: SandboxEnv(app_name, nonce, vault_table, pubsub_name)

app_name — the name passed to checkout nonce — unique random ID for this sandbox instance vault_table — a Vault table scoped to the nonce pubsub_name — unique PubSub instance name for this sandbox
