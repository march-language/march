List

List module: immutable singly-linked list operations.

List(a) = Cons(a, List(a)) Nil (built-in constructors)

Design: - Partial functions (head, tail, nth, last) panic on empty/out-of-bounds - Safe variants use the _opt suffix and return Option - fold_left is the primitive; fold_right recurses on the structure - sort uses merge sort
