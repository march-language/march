# `[P3]` Language Features

- [ ] **External function interface (C-first ABI) — remaining gaps.** The 9-phase C-first FFI (ABI core, string/Option/Result marshalling, `resource`/`consume`, interpreter dlopen path, forge `[ffi]` build integration, `blocking fn`, `gen-c` codegen, record/variant/Option/Result/List codecs, native→March upcalls, the Rust `march` crate layer) is DONE — see `specs/2026-06-19-c-ffi-abi-design.md`, `specs/c-ffi-rust-layer.md`, and `specs/c-ffi-gaps.md` for the full history. Still open: `forge ffi import` (C header → extern block, needs libclang), recursive/generic types in generated codecs (currently passthrough), multi-lib `[[ffi]]` (split out: `specs/todos/2026-06-19-ffi-multi-lib-array-of-tables.md`), and an OCaml FFI layer analogous to the Rust one (designed-for but not built).
- [ ] **MCP server for March** — split out: `specs/todos/2026-06-19-mcp-server.md`.
- [ ] **256-bit SIMD vector types (`f32x8`, `i32x8`)** — the 128-bit types (`F32x4`, `I32x4`, plus the u8x16 byte-scan kit) shipped in `stdlib/simd.march`; see `specs/progress/2026-08-10-simd-vector-types.md`. What is left is the 256-bit width. It needs a per-target ISA decision (AVX2 on x86_64 vs. two NEON registers on arm64, and the `-msse4.2` baseline the C compiler is invoked with; see `--target-cpu`, `specs/progress/2026-09-29-target-cpu-flag.md`), a tail-handling story for lengths not divisible by 8, and a scalar fallback so a program using them still compiles for a baseline CPU. The `@[vectorize]` / `@[vectorize(warn)]` attribute (2026-07-31, see the Done entry above) does not depend on these.
