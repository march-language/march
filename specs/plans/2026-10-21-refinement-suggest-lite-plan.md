# Inference-lite (`--refine-infer`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Propose, and optionally apply, every refinement the checker can already verify (scalar, element-slot, relational, abstract `Bool[p]`, fold accumulator), module-wide, with the real checker as the only oracle.

**Architecture:** The existing *assume and re-check* loop in `lib/refinecheck/precond_infer.ml` / `postcond_infer.ml` is generalised. A hypothesis is installed on a pruned decl tree (target + callers), the real checker re-walks it, and a per-site ledger diff decides. Five new modules split the work: slots, vocabulary, oracle, fixpoint driver, JSON. Output goes through `March_refactor.Refine_edit` so the CLI, forge and the LSP write identical bytes.

**Tech Stack:** OCaml 5.5.1, dune, alcotest, z3 (4.16 local, 4.8.12 CI), yojson (already used by the suggest JSON).

**Spec:** `specs/2026-10-20-refinement-suggest-lite-design.md` (read it with this plan; § references below are to it).

## Global Constraints

- The real checker is the only oracle. A `Skipped` verdict of any reason on the hypothesis's own obligation is a rejection ("not refuted" is not TRUE). (§2)
- No opened site: a hypothesis that turns any proved obligation into anything else is rejected. (§2)
- Never add `@[assume]` or `@[trusted]`. No slot of a `trusted`, `assume`, adopted-`impl`, extern or builtin function is a candidate. Refined slots are never candidates; the tool only adds. (§5.3, §5.4)
- Caller violation: a precondition that creates a *violated* site at any in-unit caller is `refused / caller-violation` with the sites listed, unless `--allow-caller-violations`. (D2)
- Public functions with no in-unit callers: proposals marked `external-callers`; `--apply` skips them unless `--apply-public`. (D3)
- New flag `--refine-infer`; `--refine-suggest*` keep their meaning and JSON byte-compatible as kind-restricted aliases (`--refine-suggest-all` = kinds `k1`, 1 round; `--refine-suggest-post-all` = kinds `k2`). (D1)
- Phase 0's change to `--refine-suggest-all`'s output ships as a `### Fixed` CHANGELOG entry. (D4)
- No stdlib annotations land in this series; stdlib files are written only with both `--refine-infer-stdlib` and `--apply`. (D5, §4.3)
- Numbers: vocabulary cap **12** per slot; global probe budget **3000** (`--refine-infer-budget`); rounds **R = 10**; demand-chain depth **3**; per-function budgets **200** (preconditions, `Precond_infer.default_budget`) and **60** (returns, `Postcond_infer.default_budget`). (§1.3, §3.3, §3.4)
- JSON `"version": 1`; `reason` is the closed set `not-true`, `not-useful`, `opens-site`, `caller-violation`, `unsatisfiable`, `handled-case`, `unannotated-signature`, `scc-unsupported`, `budget`; every array sorted by `(file, line, col, slot, kind, predicate)`. (§4.2)
- Silent caps are forbidden: `vocabulary-truncated`, `budget-exhausted`, `scc-unsupported` are reported per function, never folded into "no candidate". (§5.7)
- Output order depends only on program text; sort every `Hashtbl` walk before use. (§5.6)
- Repo rules (CLAUDE.md): `dune build --root .` with named targets; z3 on PATH; each phase lands with `specs/progress/`, a CHANGELOG bullet and `specs/lang/refinement-types.md` §"Getting a contract proposed for you" regenerated by `scripts/gen-lang-docs.py`; tests use a fresh `root`/`HOME` (a warm VC cache masks regressions); re-stage the stdlib (`dune build --root . @stdlib/default`, then `cmp`) before trusting a verdict; no attribution lines in commits.

## Review Focus

- **A multi-clause or multi-line signature** (`fn f(xs :\n List(Int)) …`, a comment inside the parameter list): `--apply` must replace exactly the annotation's bytes or report "apply by hand". Pinned in Task 12.
- **The same function name in two modules of one unit** (`A.go`, `B.go`): call graph, caller pruning and JSON must use qualified names and never cross-attribute a caller. Pinned in Task 2.
- **A file that does not type-check or parse**: `--refine-infer` must exit non-zero with the compiler's own diagnostics and write nothing, never propose on a half-typed tree. Pinned in Task 11.
- **A caller in another file of the unit (MARCH_LIB_PATH)**: caller-impact must see it; a function whose only callers are outside the unit is `external-callers`, not "no callers". Pinned in Task 2.
- **Rerunning after `--apply` with a warm VC cache**: proposes nothing (idempotence) and still predicts exactly; tests run it in the same `root` twice. Pinned in Task 12.
