# Wave 1 — pipeline deep review P0 fixes (2026-07-01/02, `specs/analysis/2026-07-01-pipeline-deep-review.md`)


- ✅ **B3 — guard exhaustion returned literal `0` instead of panicking (lower.ml)** — commit `11925401`. Exhausted match guards now hoist the existing `nonexhaustive_panic` into both `compile_matrix_impl` fallbacks instead of fabricating a pointer-unsafe `LitInt 0`.
- ✅ **B4 — `PatRecord` and float-literal match arms silently dropped from match compilation (lower.ml, llvm_emit.ml)** — commit `e8a43b7b`. `pat_tag_and_subs` now handles both shapes; the swallowing `None -> ()` in the grouping loop fails loudly on any future unhandled kind instead of discarding the arm.
- ✅ **B9 — off-by-one in the `march_` runtime-extern prefix guard (llvm_emit.ml)** — commit `cd0770d9`. `String.sub n 0 7` (7 chars) vs the 6-char literal `"march_"` made the runtime-extern-as-first-class-value arm dead; fixed to match the three sibling `0 6` checks.
- ✅ **B10 — RC ops (`EIncRC`/`EDecRC`/`EFree`) skipped by name against top_fns/builtins with no shadow guard (llvm_emit.ml)** — commit `b98115da`. A local binding named `link`/`send`/etc. now gets correct RC ops; the five RC arms gained the `var_slot` shadow check `emit_atom` already applied twice.
- ✅ **B5 — `EUpdate` on a type-erased record wrote past the allocation (llvm_emit.ml + runtime)** — commit `0d1a829e`, see full entry above (Task 5).
- ✅ **B15 — raw newline inside a string literal desynced all subsequent diagnostic line numbers (lexer.mll)** — commit `f169070c`. `read_string`/`read_string_interp` now call `Lexing.new_line` on an embedded raw `\n`, matching the triple-quoted-string path.
- ✅ **FLOAT-filter — float-literal match arms failed to parse without a leading `|` (token_filter.ml)** — commit `6e376e4d`. Added `Parser.FLOAT` (and audited sibling literal tokens) to `is_pattern_start`.
- ✅ **B6 — pipe into a parenthesized `match` silently discarded the scrutinee (desugar.ml)** — commit `b579f848`. `x |> (match scrut do ... end)` now errors with a positioned diagnostic instead of matching on `x` and dropping `scrut`.
- ✅ **B14 — interleaved same-name fn clause groups silently shadowed the earlier group (parser.mly)** — commit `4cdc65de`. `group_fn_clauses` now rejects a fn name recurring in a non-adjacent group at the same level instead of leaving the first group as dead code.
- ✅ **B16 — `~H` sigil CSRF auto-injection referenced a free variable `conn` (desugar.ml)** — commit `f39a5c49`. Removed the unconditional CSRF-tag injection on `<form method=post/put/patch/delete>`, which broke every non-Bastion `~H` user (worse with bastion leaving the stdlib) — see `project_bastion_removal` context.
- ✅ **B7 — mutual-TCO back-edge dropped the Perceus dec-chain (llvm_emit.ml)** — commit `05d9e46b`. Added mutual-group twins of the self-TCO `ELet`/`ESeq` interception arms so the dec-chain emits before the back-edge instead of landing in a dead block (was an RC leak every loop iteration).
- ✅ **B8 — mutual-TCO loops had no reduction check, could starve the scheduler (llvm_emit.ml)** — commit `bc5b0e22`. `emit_reduction_check` now runs after the `mutual_loop` label, mirroring the self-TCO path.
- ✅ **B12 — `cur_type_defs` global left stale for every REPL/fragment emitter (llvm_emit.ml)** — commit `53c70a0e`, see full entry above (Task 8). Type defs are now a `ctx` field; the global is deleted.
- ✅ **B11 — REPL closure wrapper missed the uniform ptr-ABI fix (llvm_emit.ml)** — commit `b32d8569`, see full entry above (Task 9). The inline wrapper is gone; `emit_repl_fn_with_closure_slot` calls the canonical `clo_wrap_define`.
