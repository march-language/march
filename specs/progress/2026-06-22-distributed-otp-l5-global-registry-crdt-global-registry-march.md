- ✅ **Distributed OTP — L5 global registry CRDT (`global_registry.march`, 2026-06-22)** — `GlobalRegistry`: the cluster-wide name registry as a composite CRDT mapping `name → {node_id, pid}`. Each binding carries a `VectorClock` (causally orders updates to that name) + a presence bit so `unregister` converges like an LWW-element-set removal. Per-name resolution: causally-newer wins (`VectorClock.compare` → `After`); older/`Equal` keeps existing (idempotent); `Concurrent` broken by a deterministic `(node_id, pid)` tiebreak → every replica converges. `merge` is associative/commutative/idempotent (the gossip/anti-entropy join). API: `register`/`unregister`/`lookup`/`contains`/`names`/`size`/`observe`/`merge`; built on the `VectorClock` primitive. 11 TDD asserts (`test_global_registry.march`: register/lookup, tombstone, causal override + stale-ignore, concurrent convergence both orders, idempotence, union, removal-converges).
