- ✅ **Refinement types: measure axioms M-a (quantified recursion equations) + M-b (soundness gate + built-in `List`) (2026-06-21)** — **M-a**: a `@[measure]` over a user ADT is *axiomatised*, not just reflected symbolically. The ADT is modelled with `declare-datatypes` (element type opaque `Elem`, self-recursive fields), the measure as an uninterpreted `declare-fun`, and each `match` arm as a `:pattern`-triggered recursion-equation axiom — so the solver computes measure values *structurally* (`size(Node(Leaf,x,Leaf)) = 1`, out-of-bounds tree indices caught). 3s solver timeout keeps hard quantified queries `unknown` → definite-failure skip (never hang, never unsound). **M-b**: (1) the **hard soundness gate** — a `@[measure]` is a promise of a total, terminating, pure function; the encoding trusts it, so a measure that is effectful (`spawn`/`send`/`dbg`/`assert`), divergent (`panic`/`todo`/`exit`), non-total (a `/`/`%` that can divide by zero, or a non-exhaustive `match` on its ADT param), or not structurally recursive (a recursive call whose argument is not a component of the matched parameter) is now a **compile error**, not a silent symbolic fallback (a sound-but-unaxiomatisable measure — multi-arg, element-inspecting, `let`-bodied — still falls back silently). (2) **built-in `List(a)`** modelled as `Nil | Cons(a, List(a))`, so user list measures (`length`) axiomatise like user ADTs (`length([10,20]) = 2`). (3) datatype sort names moved to a private `M_` namespace so no ADT name collides with a z3-reserved sort (`List`, `Array`, `Seq`, …); axiom bodies restricted to self-recursion only (cross-measure/`len` calls deferred to M-c — their symbols aren't declared). 6 new tests (40 total in `test/test_refinecheck.ml`). **Remaining (per spec):** M-c (measures calling measures, mutual recursion, mutually-recursive datatypes), M-d (relational postconditions like `size(insert(t,x)) == size(t)+1`), performance measurement / flag-gating.
