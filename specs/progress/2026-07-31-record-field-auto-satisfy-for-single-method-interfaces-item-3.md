- ✅ **Record field auto-satisfy for single-method interfaces (Item 3)** — When discharging `CInterface(Iface, TRecord[...])` with no explicit `impl`, the typechecker now auto-satisfies if the interface has exactly one accessor method (`a -> T`) and the anonymous record has a matching field with the correct return type. `discharge_constraints` checks `env.interfaces`, inspects the single method's surface type, converts the return type with `surface_ty`, and uses `impl_matches_ty` for a pure structural comparison. Named types (`TCon`) never auto-satisfy — they require explicit `impl` declarations. 9 new tests in `record_auto_satisfy` group covering: matching field (ok), wrong type (error), missing field (error), multi-method interface (no auto), binary method (no auto), named type (no auto), named type + explicit impl (ok), when-constraint (ok), two record shapes (ok).
