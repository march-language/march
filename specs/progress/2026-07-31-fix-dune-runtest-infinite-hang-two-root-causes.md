- ✅ **Fix `dune runtest` infinite hang (two root causes)** — `dune runtest` was hanging indefinitely on every run due to two independent bugs. (1) `lib/eval/compress_stubs.c`: `caml_march_deflate_decode` (and `caml_march_gzip_decode`) entered an infinite loop when `inflate()` returned `Z_BUF_ERROR` with all input consumed but no `Z_STREAM_END` — malformed input (e.g. the 3-byte `[1,2,3]` test vector) caused this on every run of the "deflate decode invalid → Err" test. Fix: explicit guard that detects `avail_in == 0 && avail_out > 0` after `Z_BUF_ERROR` and calls `caml_failwith`. (2) `test/test_heap.c` section 5c + `runtime/march_gc.c`: the GC abort-path tests fork child processes that call `abort()` via `march_gc_collect` → `gc_corrupt`. On macOS, `abort()` after `fork()` triggers the system crash reporter (ReportCrash), which intercepts the Mach exception and stalls for 10+ minutes per child process. Fix: added a weak `march_gc_crash()` hook in `march_gc.c` (defaults to `abort()`); the test binary overrides it with a strong definition that calls `_exit(134)` (128+SIGABRT convention), bypassing ReportCrash entirely. `expect_abort()` updated to accept both `WIFSIGNALED(SIGABRT)` and `WEXITSTATUS==134`. Full suite now completes in ~90s.
