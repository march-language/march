- ✅ **JIT monomorphization: TVar "_" wildcard specialization + Map.insert hash dispatch** — Two correctness fixes in `lib/tir/mono.ml`. (1) `match_ty`: `TVar "_"` (the lowering placeholder for spans absent from the REPL type_map) is now treated as lower-priority than any concrete type, so `{b→Int}` correctly replaces a spurious `{b→TVar "_"}` binding. Without this, `fold_left$List_Int$Int` recursively called the generic `fold_left$List_Int$V__` instead of itself, halving every result. (2) `rewrite_calls`: the "already monomorphic" guard now also excludes functions with `TVar "_"` params. Without this, `Map.key_hash(k : TVar "_")` was emitted as-is; the internal `hash(k)` call stayed as bare `@hash`, which resolves to OCaml's `hash.c` that asserts on non-integer inputs — crashing on any `Map.insert` call in JIT mode. Also updated `test/repl_smoke_test.sh` to correct match syntax, fold arg order, and Map test expectations (map now displays `HamtMap(HEmpty/HLeaf(...))`).
