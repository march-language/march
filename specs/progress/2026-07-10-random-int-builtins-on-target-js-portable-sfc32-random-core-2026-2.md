- ✅ **Random + int builtins on `--target js`; portable sfc32 Random core (2026-07-10).** Resolves the 2026-07-09 Starfling P1 ("`Random` unusable on `--target js`"). Three parts. **(1) JS mappings for the int builtins** — `int_and/or/xor/not/shl/shr/popcount/mod/div/mod_euclid/div_euclid` now delegate to new checked implementations in `runtime/march_runtime.mjs` that mirror the INTERPRETER's semantics (`int_shr` is a logical shift of the 63-bit pattern; `int_popcount` flips the sign bit before counting) exactly within the double-exact range ±(2^53−1) and **throw RangeError rather than silently round** beyond it; fast paths (int32, and non-negative split into 2^32-radix words) keep hot code off BigInt entirely (~35 ns/op vs ~53 ns/op BigInt path, node 25). Also mapped: `int_abs`, `unix_time`, `float_abs/floor/ceil`, and `float_round` (half-away-from-zero via `march_float_round` — JS `Math.round` differs on negative halves).
