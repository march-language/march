- ✅ **`Xml` stdlib module — non-validating XML parser** — `stdlib/xml.march`: pure-March iterative stack-based XML parser (no FFI, namespace-unaware). Handles: elements, attributes (double/single-quoted), text nodes, CDATA sections, comments, processing instructions, XML declaration (skipped), DOCTYPE (skipped), entity references (`&lt;` `&gt;` `&amp;` `&quot;` `&apos;`), self-closing tags, nested elements of arbitrary depth. Stack-based design (`XmlFrame` type) eliminates mutual recursion between element/content parsing — all recursive calls are tail calls. Public API: `parse/1`, `parse_exn/1`, `root/1`, `tag/1`, `text/1`, `attr/2`, `children/1`, `elements/1`, `find/2`, `find_all/2`, `elem/3`, `text_node/1`, `to_string/1`, `to_string_pretty/1`. `~xml"..."` sigil added to `stdlib/sigil.march`. 40 tests in `test/stdlib/test_xml.march`. Wired into `bin/main.ml`, `test/test_stdlib_march.ml`, and `sigil.march`.
