- ⏳ **Small-string optimization (planned, not started):** `specs/plans/2026-07-27-string-sso.md`. Store ≤7-byte strings inline in the value using March's existing tagged-immediate scheme — `IS_HEAP_PTR` already rejects sign-bit-set values, so `march_incrc`/`march_decrc` need **no changes**, and it is not a type-system change. Measured ceiling: ~53% of allocations in real web templating (`bench/iolist_template`), against 42% in the synthetic churn benchmark. Two other workloads measured higher and are misleading — the CSV split is synthetic with 3-byte fields, and JSON's 90% is an artifact of a parser allocating 2.03 strings per input byte. Standing caution recorded in the plan: an SSO makes allocation-heavy code look fast without fixing it.
