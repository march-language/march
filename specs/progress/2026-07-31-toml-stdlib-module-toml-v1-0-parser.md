- ✅ **`Toml` stdlib module — TOML v1.0 parser** — `stdlib/toml.march`: pure-March recursive-descent TOML v1.0 parser (no FFI). Handles: basic/literal/multiline strings (with escape sequences), integers (signed, underscore separators), floats (decimal, scientific notation, inf/nan via `string_to_float`), booleans, arrays, inline tables, `[table]` headers, `[[array-of-tables]]` headers, dotted keys, quoted keys, comments. Public API: `parse/1`, `parse_exn/1`, `to_string/1`, `get/2`, `get_in/2`, `get_str/2`, `get_int/2`, `get_float/2`, `get_bool/2`, `get_table/2`, `get_array/2`. `~toml"..."` sigil added to `stdlib/sigil.march`. 157 tests in `test/stdlib/test_toml.march`. Wired into `bin/main.ml`, `test/test_stdlib_march.ml`, and `sigil.march`.
