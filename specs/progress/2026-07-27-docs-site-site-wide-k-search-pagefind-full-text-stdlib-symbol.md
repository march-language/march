- ✅ **Docs site: site-wide ⌘K search (Pagefind full-text + stdlib symbol lookup) (2026-07-27, `docs/_includes/search.html`, `scripts/build-search-index.sh`, `scripts/serve-docs.sh`, `.github/workflows/deploy-pages.yml`, four `docs/_layouts/*.html`).** march-lang.org had no search outside the generated API reference. Pagefind now runs as a post-build step over `_site/` — the only point at which the ~53 Jekyll pages and the 114 standalone HTML pages emitted by the external `march_doc` tool are the same kind of artifact — indexing 167 pages, shipping with the site, no runtime search service. Pages opt in via `data-pagefind-body`, which Pagefind treats as exclusive once any page has it, so the playground/Tetris/perihelion/graph pages need no exclusion rules; the stdlib pages get the attribute injected into the BUILD OUTPUT (not the committed files) so a regeneration can't undo it. The same modal also loads `march_doc`'s existing `search-index.json` (2038 symbols, ~57 KB gzipped, lazy) and shows a capped "Standard library" group linking to definition anchors (`Array.html#fn-push`) — symbol lookup previously worked only from inside the API reference. Symbols match on NAME only, exact or prefix, so prose queries return prose alone (verified: `how do supervisors restart children` → zero symbols). **Non-obvious bug found in review:** the full-screen scrim covered only a sliver of the page — not z-index, but the CSS containing-block rule: `.d-nav`/`.m-nav` set `backdrop-filter`, which makes an element a containing block for `position: fixed` DESCENDANTS, and the layouts render the include inside the nav. Measured 846×126 (nav box) vs 846×998 (viewport) after reparenting to `<body>`. **Guard:** the index script fails the build below 100 indexed pages — Pagefind exits 0 and still writes a `pagefind/` directory when it indexes nothing, so a dropped attribute would otherwise ship a dead search box on a green CI run. **Open follow-up:** the 114 API pages keep their own ⌘K, so the keystroke still means something narrower there; unifying needs a change in the separate `march_doc` repo plus regenerating all 114 files.
