- ✅ **Perceus whole-scrutinee-escape rewrite (rc50)** — Fixes a residual RC underflow / heap corruption (`march: local RC underflow at 0x… — aborting`) that survived commit `6065f30`'s field-escape fix whenever a pattern-match arm returned the *whole* scrutinee instead of an escaping field. The rc50 reproducer (`drop_blank`/split-last pattern) crashed because `Perceus.add_scrutinee_free_for` skipped `dec_rc ls` when `ls` was free in the arm body (`_ -> ls`), while the extracted field `l` was still classified as owned and got a `dec_rc l` after a borrowed-callee use (`trim(l)`) — so the aliased string's RC underflowed. Fix in `lib/tir/perceus.ml`: new **Phase 0.5** preprocessing pass (`preprocess_scrut_escape` + `rewrite_scrut_tail` + `scrut_escape_field_atoms`) rewrites every tail-position `EAtom (AVar scrut)` inside a destructuring ECase arm into `EAlloc (TCon "T.Ctor", [field atoms])`. After rewrite the scrutinee is no longer free in the body, so `add_scrutinee_free_for` emits the usual arm-start `dec_rc ls`, which `llvm_emit.strip_scrut_decrc` then converts into a conditional `march_decrc_freed` + per-field IncRC on the shared path (matching the field-escape fix's runtime contract). FBIP reliably folds the reconstruction into `reuse ls as T.Ctor(...)` when the decref'd cell is unique, so there is no net allocation on the hot path. Helper walks `let v = $fN` rebinds to pick up properly-typed field atoms introduced by `Lower` and falls back to raw `br_vars` (placeholder-typed) when no rebind exists. Regression test `test_perceus_scrut_escape_rewrite` in `test/test_march.ml` (`perceus` group) verifies the Cons arm of a `match ls do … SCons(h, rest) -> ls end` function ends in an `EAlloc`/`EReuse` reconstruction and no tail position bears the bare scrutinee.
