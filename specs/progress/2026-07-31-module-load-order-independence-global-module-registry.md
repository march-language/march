- ✅ **Module load-order independence (global module registry)** — `lib/eval/eval.ml`: `module_registry` hashtable (64-slot) populated as each `DMod` is evaluated. `EField` qualified lookups check the registry at call time (after the lexical env), so closures captured in one module can call functions from another module even if that module is evaluated later in the file. `lookup` fallback also checks the registry for dotted names not found in the lexical env. Registry cleared at the start of `eval_module_env` to keep runs isolated. Tests added in `test/test_march.ml`.
