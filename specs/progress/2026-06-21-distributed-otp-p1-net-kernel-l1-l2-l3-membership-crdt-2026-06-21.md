- ✅ **Distributed OTP — P1 net-kernel (L1+L2) + L3 membership CRDT (2026-06-21)** — Eight new stdlib modules building the authenticated peer connection + member set, plus a compiler change to expose raw TCP accept. **L1/L2 (transport + net-kernel):** `net_frame` (`NetFrame`, length-prefixed partial-read-safe framing), `node_identity` (`NodeIdentity`, `{name, NodeId=sha256(pubkey), incarnation}` + msgpack codec), `cluster_auth` (`ClusterAuth`, shared-secret HMAC challenge/response), `handshake` (`Handshake`, `Hello` codec + `authenticate` — proof must bind to the nonce we issued), `net_kernel` (`NetKernel`, byte bridge `List(Int)`↔Socket `String` + framed `send_frame`/`recv_frame` + symmetric authenticated `handshake` over a socket), `peer_registry` (`PeerRegistry`, one-connection-per-peer table by NodeId), `cluster_conn` (`ClusterConn`, `listen`/`connect_to_peer`/`accept_one` lifecycle). **L3:** `membership` (`Membership`, SWIM-style member view `{Alive|Suspect|Dead, incarnation}` with a CRDT merge = lexicographic max over `(incarnation, severity)`; associative/commutative/idempotent so gossip converges). **Compiler:** `tcp_listen`/`tcp_accept` are exposed to March (`Int -> Result(Int, String)`) — typecheck sigs + `IO.NetListen` cap, eval `Unix` impls returning a tagged `Result` (the runtime + codegen already had the raw-int64 primitives; the typechecker didn't, so the server-accept side was unwritable).
