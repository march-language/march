- ✅ **`Yaml` stdlib module — YAML 1.2 subset parser** — `stdlib/yaml.march`: pure-March YAML parser (no FFI). Handles: block mappings, block sequences, plain/single-quoted/double-quoted scalars, flow sequences `[]`, flow mappings `{}`, comments `#`, document separator `---`, implicit type coercion (bool/null/int/float). `YamlValue` type: `YStr | YInt | YFloat | YBool | YNull | YSeq | YMap`. Public API: `parse/1`, `parse_exn/1`, `get/2`, `get_in/2`, `get_str/2`, `get_int/2`, `get_bool/2`, `get_seq/1`, `to_string/1`. `~yaml"..."` sigil added to `stdlib/sigil.march`. 36 tests in `test/stdlib/test_yaml.march` (scalars, block seq/map, nested, comments, doc sep, flow, navigation, to_string, errors, sigil). Wired into `bin/main.ml`, `test/test_stdlib_march.ml`, and `sigil.march`.
