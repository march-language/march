- ✅ **`forge notebook` ergonomics (Livebook-class UX)** — `forge/tasks/notebook_server.march`: (1) Auto-print REPL semantics — each code cell wrapped in `pfn __cell_N__()`, last expression captured and printed if `to_string(__r__) != "()"`, giving Jupyter-style auto-output without explicit `println`. (2) Execution timing — client records `Date.now()` on `running` message and computes elapsed on `output`; displayed as `· 42ms` or `· 1.2s` in the cell gutter. (3) Shift+Enter muscle memory — runs current cell and advances focus to the next cell (or creates a new one if at the end), matching Jupyter workflow. (4) Inline HTML/SVG rendering — `renderOutput(text)` detects `<svg`, `<table`, `<!DOCTYPE`, `<html` prefix and renders as raw HTML in `.cell-out-html` div instead of escaped text; enables rich DataFrame tables and Plot SVG charts. (5) Styled `.cell-out-html` CSS — dark-theme table styling (purple column headers, row hover, monospace font); SVG auto-scaled to container width. (6) Bug fixes: `make_cell_fn` and `generate_server_runner` now strip trailing `\n` before splitting (prevents empty indented lines that cause parse errors); empty cell bodies emit `()` instead of empty function body (which is a parse error). `stdlib/dataframe.march`: `DataFrame.to_html(df)` — renders a DataFrame as a styled HTML table string; auto-detected by the notebook renderer and displayed inline; `pfn html_esc` helper for XSS-safe attribute/text encoding; caption shows row × column counts.
