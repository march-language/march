- ✅ **`stdlib/string.march` claimed an SSO that does not exist (2026-07-27).** The module header had stated since 2026-03-19 that "the runtime uses a fat-pointer representation with small-string optimisation (SSO): strings of 15 bytes or fewer are stored inline without a heap allocation." Never true — every string is a refcounted heap allocation with a 24-byte header. Actively misleading for anyone reasoning about allocation cost, and it contradicts the measured phase 1 profile. Corrected, and `grapheme_count`'s docs now state that it counts codepoints despite the name, with the concrete divergent cases (combining marks, ZWJ sequences).
