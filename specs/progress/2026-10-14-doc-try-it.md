# "Try it" buttons on the stdlib API reference (2026-10-14)

Design: `specs/2026-10-14-doc-try-it-design.md`. This is project 3 of 4 toward runnable
documentation examples.

- `march_doc` (march-language/march_doc, branch `feat/try-it`):
  - `--try-it` / `--site-base` flags;
  - `Markdown.md_to_html_mode` marks runnable blocks (`data-try`,
    `data-try-kind`);
  - `TryIt.panel`: the sidebar REPL and button script, emitted only on pages with
    something to run. The REPL loads on the first click.
  - Also fixed: an attribute line (`@[assume]`, ...) between `doc` and `fn` dropped the
    doc, which affected 56 stdlib declarations.
- This repo:
  - `forge doc --try-it [--site-base]` passes the flags through;
    `scripts/gen-stdlib-docs.sh` uses `--try-it`;
  - `-- doc: try` on the 14 stdlib files whose `march>` examples can run in a browser;
  - `march-repl.js` gains `run(code)` and an in-order run queue. Before, inputs
    submitted while the interpreter loaded were dropped, and a failed download hung;
  - `hash_map.march` examples are indented, so they render as code;
  - `scripts/check-doc-try-it.js` replays every "Try it" example on the committed
    pages (new `browser-repl` CI step).
- Results:
  - 107 "Try it" examples (199 inputs) on 14 pages, all running;
  - stdlib entries with no description: 616 → 573; Set 16 → 2; Map, LinearMap and
    Array → 0.
- Checked in a browser (Jekyll):
  - nothing fetched before the first click;
  - Http `parse_url` and `encode_query` examples run in order in one session;
  - clear, reset and close work;
  - BigInt (nothing opted in) has no sidebar.
- Package docs: not possible on the registry, whose CSP is `script-src 'self'`; that
  needs its own design.
