- ✅ **TOML type-conflict detection for table headers** — `stdlib/toml.march`: `ensure_table_at_path` silently replaced non-table values (e.g. `TInt`) with an empty subtable when processing `[a.b]` after `a = 1`, returning Ok instead of an error. Fix: return `[("__toml_conflict__", TNull)]` sentinel on type mismatch and propagate via `is_err_marker` check in the caller, which converts it to `Err(TomlError("type conflict at table header: ...", ...))`. Fixes the failing `"type conflict at key path is an error"` test in `test_toml.march`.
