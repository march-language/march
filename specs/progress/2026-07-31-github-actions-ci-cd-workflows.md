- ✅ **GitHub Actions CI/CD workflows** — `.github/workflows/build.yml` (reusable matrix build: macOS arm64, macOS x86_64, Linux x86_64 static); `.github/workflows/release.yml` (tag-triggered release: builds all platforms, uploads binaries, generates SHA256 checksums, creates GitHub Release with install instructions); `.github/workflows/nightly.yml` (scheduled 02:00 UTC nightly build with Slack/artifact notifications); `.github/workflows/ci.yml` (PR/push CI on macOS + Ubuntu). `scripts/marchup` — POSIX shell installer: detects platform, downloads matching binary from GitHub Releases, installs to `~/.march/bin`, updates PATH in `.bashrc`/`.zshrc`. Spec: `specs/github_release_builds.md`.
