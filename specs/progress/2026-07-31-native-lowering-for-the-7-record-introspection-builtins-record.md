- ✅ **Native lowering for the 7 record introspection builtins (record shape registry)** — `record_keys`, `record_values`, `record_entries`, `record_get`, `record_put`, `record_has_key`, `record_from_list` were interpreter-only; native builds emitted bare `call ptr @record_entries(...)` and died at link time. Records carry no field names at runtime, so a shape registry was added to `runtime/march_extras.c`: every record allocation (`ERecord`/`EUpdate`/`EReuse`) stamps an interned **shape id** into the previously-unused header pad word (offset 12, always 0 via `march_alloc`'s calloc) referencing a descriptor `"name:kind;..."` with per-field kind chars (`i` raw i64 scalar / `f` double bits / `p` heap ptr / `g` generic). The builtins are C functions reading the descriptor; `record_put` with a new key and `record_from_list` **intern new shapes at runtime** (sorted insert), supporting depot's dynamic `Depot.Schema.blank` fold. Value conventions: record slots natural repr; outputs into generic ADT slots (values list payload, `record_get`'s `Some` payload) low-bit-tag ints; `record_entries` pair snd stays natural per field kind. `llvm_emit.ml` special-cases the seven `EApp`s (natural-repr value passing + kind-char args, `record_from_list` payload-kind hint), and `EField` on statically-unknown record types now emits a dynamic by-name lookup (`march_record_field_dyn`, legacy slot-0 read for shape-0 cells). Eval's `record_keys/values/entries` now sort by field name to match the native sorted-by-name layout. Two enabling fixes shipped together: (1) `lower.ml` `rename_tir_vars` is now scope-aware — a local binder sharing a module fn name (e.g. a param named `fields` in a module defining `fn fields/1`) no longer has its references rewritten to the qualified global (was emitted as an undefined zero-arg call `@Depot.Schema.fields()`); (2) structural `==` for **tuples and records** — `ensure_adt_eq_fn` generates element-wise short-circuiting eq for `TTuple`/`TRecord` (previously pointer comparison, so `List.member(record_entries(r), ("age", 30))` was always false natively). WASM targets skip shape stores. Fixture: `test/imports/record_native/` (18 checks, compile-and-run). Borrow table: all `record_*` args borrowed.
