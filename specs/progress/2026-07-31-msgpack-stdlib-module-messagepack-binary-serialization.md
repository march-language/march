- ✅ **`Msgpack` stdlib module — MessagePack binary serialization** — `stdlib/msgpack.march`: pure-March MessagePack encoder/decoder with no external dependencies. `Value` type: `Null | Bool(Bool) | Int(Int) | Str(String) | Bin(List(Int)) | Array(List(Value)) | Map(List((Value, Value)))`. Full format coverage: fixint (−32–127, 1 byte), int8/uint8/int16/uint16/int32/uint32/int64/uint64 (2–9 bytes), fixstr/str8/str16/str32, fixbin/bin8/bin16/bin32, fixarray/array16/array32, fixmap/map16/map32, fixnull/bool. Integer arithmetic avoids `float_bits` (uses sign-extension via `hi_s = if b0 >= 128 do b0 - 256 else b0 end` for 63-bit safe int64 reconstruction). `impl Eq(Value)` with recursive structural equality helpers. Public API: `encode/1`, `decode/1`, `decode_all/1`, plus convenience constructors `null/0`, `bool/1`, `int/1`, `str/1`, `bin/1`, `array/1`, `map/1`. 195 unit tests in `test/stdlib/test_msgpack.march` + 12 Msgpack property tests added to `test/stdlib/test_properties.march` (round-trips for all value types, encode non-empty invariant, fixint 1-byte invariant, decode_all list recovery).
