- ✅ **`forge test` compile pipeline + shared CAS** — `forge test` now compiles and runs tests via the same compile pipeline as `forge build` (`march --compile --test`) instead of the interpreter. Test binaries land in `.march/build/test/<name>_test` (same CAS as build). `forge build` explicitly excludes test files (`test_*.march`, `*_test.march`) from the production binary. Fallback to interpreter when `MARCH_TEST_INTERPRETER=1` or `--coverage`. Key changes: `march --compile --test` flag (`bin/main.ml`); `DTest`/`DDescribe`/`DSetup`/`DSetupAll` lowered to zero-arg TIR functions (`lib/tir/lower.ml`); `tm_tests : (string * string) list` field on `tir_module`; synthetic test-runner `@main` emitted in `llvm_emit.ml` (calls `march_test_init`/`march_test_setup_all`/`march_test_run`/`march_test_report`); setjmp/longjmp test isolation harness in `runtime/march_runtime.c/.h` (`march_test_init`, `march_test_run`, `march_test_setup_all`, `march_test_report`); ctor_info suffix-search in `llvm_emit.ml` now resolves ambiguous constructor names by arity instead of hashtable order.
