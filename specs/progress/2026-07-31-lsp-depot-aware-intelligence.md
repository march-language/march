- ✅ **LSP Depot-aware intelligence** — New `lsp/lib/depot.ml` module gives the LSP understanding of the Depot query-builder / schema / migration library. Schema model (A0–A3): extracts `Depot.Schema.define` calls into `depot_schemas`; resolves `from_table("t") |> where_eq("col", v)` pipes to their schema via `depot_col_occs`. Column intelligence (B1–B3): column-name completion inside `where_eq`/`order_asc`/… args; `depot/unknown-column` Warning with Levenshtein did-you-mean; go-to-def jumps to the field's span in the schema; hover returns the field type. Table intelligence (B4): table-name completion in `from_table` args; `depot/unknown-table` Warning with did-you-mean. Migration intelligence (C1–C4): `migration_ops` extracts `CreateTable`/`AlterTable`/`CreateIndex`/`References` ops; `depot/schema-drift` and `depot/missing-migration` Hints compare schemas vs migrations; `depot/unknown-fk-column` Warning for bad `references(table, { column = … })`. SQL injection (D1): `depot/sql-injection` Warning when `Connection.simple_query` gets a non-literal SQL arg. All conservative: silent when schema/table is unresolvable. +19 LSP tests (**319** total `march-lsp`). Files: `lsp/lib/depot.ml` (new), `lsp/lib/analysis.ml` (extended), `lsp/test/test_lsp.ml`.
