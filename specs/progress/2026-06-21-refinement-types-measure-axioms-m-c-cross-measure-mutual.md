- ✅ **Refinement types: measure axioms M-c (cross-measure + mutual recursion) + performance/flag-gating (2026-06-21)** — **M-c**: lifted M-b's self-recursion-only restriction. A `@[measure]` may now call *another axiomatisable measure* (argument still required to be a structural component, so every call — self or cross — decreases and the whole system is total). Axiomatisability is resolved by a **greatest fixpoint** over the candidate set (a measure calling a non-axiomatisable one cascades to symbolic), and all `declare-fun`s precede all axioms so forward/mutual references resolve. **Mutually-recursive datatypes** are emitted as the transitive ADT closure in one combined `declare-datatypes`, and a constructor field of *any* registered ADT (not just self) reflects to that ADT's sort so cross-ADT calls are well-sorted. Verified: `tsize`/`fsize` over mutually-recursive `RTree`/`RForest` compute structurally (depth-2 forest → size 2, out-of-bounds caught). Gate still covers self-recursion; a non-structural mutual cycle isn't a hard error but stays unaxiomatised (sound symbolic fallback). **Performance + flag-gating**: measured the cost (cold VC cache) — 40 concrete-structure measure-bound VCs take **69.9 s** with axioms vs **0.45 s** symbolic (~155×; many near the 3 s timeout), but warm-cache rebuilds are ~0.5 s. Key fix: the datatype/quantifier preamble is now attached to a VC **only when it references an axiomatised measure** (postconditions, which reflect measures symbolically, never get it), so 150 plain Int/Bool VCs alongside a defined measure cost ~1 s — the axiom tax is isolated to measure-using VCs. New `--no-measure-axioms` flag reflects measures symbolically and disables the gate (changes only diagnostics, not the artifact, so not in the CAS key). Axioms stay **on by default** (non-measure code unaffected; measure consumers are rare; warm cache covers iterative dev). 6 new tests (46 total in `test/test_refinecheck.ml`: 3 mutual-recursion, 3 flag-gating). **Remaining:** M-d (relational postconditions — needs reflecting an operation's *result* as a datatype term); a measure call on the whole matched value (`A(t) = B(t) + …`); per-query timeout tuning.
