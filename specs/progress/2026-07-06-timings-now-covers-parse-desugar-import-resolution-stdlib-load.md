- ✅ **`--timings` now covers parse/desugar/import-resolution/stdlib-load, not just typecheck-onward (`bin/main.ml`, `test/test_properties.ml`, 2026-07-06).** Investigated as part of a compile/typecheck-speed opportunity sweep: the `--timings` flag's clock (`t_compile_start`) was only started after the frontend (parse, desugar, cross-file import resolution, stdlib load) had already finished, so the cost of re-parsing/re-typechecking the ~108-module stdlib on every invocation — often the dominant cost for small user programs — was invisible. Moved the timer to start right before parsing and added `"parse"`/`"desugar"`/`"resolve-imports"`/`"stdlib-load"` stamps ahead of the existing `"typecheck"`-onward ones (which are unchanged, just now measured from an earlier, more accurate start point). New unit test `test_timings_covers_frontend` in `test/test_properties.ml`.
