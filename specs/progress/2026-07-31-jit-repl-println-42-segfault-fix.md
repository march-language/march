- ✅ **JIT REPL `println(42)` segfault fix** — `println(42)` (and any prelude fn called with a non-string literal) caused SIGSEGV in JIT. Root cause: `lower_module`'s Pass 2 iterated only `m.mod_decls`, so top-level `DFn` declarations from `stdlib_context` (prelude fns like `println`, `str`, `map`) were never lowered into `fn_table`. With no `fn_table` entry, mono could not specialize `println$Int`; the LLVM emitter fell back to `mangle_extern` and emitted `call void @march_println(i64 42)` — a C runtime call with wrong arg type — causing SIGSEGV. Fix: added a pre-pass before Pass 2 in `lib/tir/lower.ml` that lowers `DFn` from `stdlib_context` (excluding `DMod`/`DImpl`, which are handled lazily). Also fixed four `EApp` sites in `lower.ml` that used `unknown_ty` instead of concrete `TFn` types for builtin operator references, and added `march_compare_*/march_hash_*` to `builtin_ret_ty` in `llvm_emit.ml`.
