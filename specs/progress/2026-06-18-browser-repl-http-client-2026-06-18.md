- ✅ **Browser REPL HTTP client (2026-06-18)** — `HttpClient.get` / `HttpClient.post` now work in the js_of_ocaml playground via a synchronous-XHR platform hook. New `http_fetch` / `http_fetch_available` builtins (`lib/eval/eval.ml`) with a `http_fetch_hook` ref; native leaves it unset and keeps the socket transport, the browser build (`js/march_browser.ml`) sets it to a sync `XMLHttpRequest` impl. `HttpTransport.request` branches on `http_fetch_available()` (handles both http and https in the browser, bypassing the native `require_plain_http`/TLS path). `http.march`/`http_transport.march`/`http_client.march` added to the browser stdlib loadlist. CORS-limited, non-streaming, server side still unsupported. 5 new eval tests; verified end-to-end via a Node bundle smoke test with a polyfilled sync XHR.
