- ✅ **Property-based testing stdlib (Hedgehog-style integrated shrinking)** — New `stdlib/gen.march` + `stdlib/check.march` modules plus `__try_call` runtime builtin. `Gen` provides rose-tree-based generators with laziness (`GenTree(a) = GenTree(a, Thunk(Bool -> List(GenTree(a))))`): primitives (`int`, `bool`, `float`, `constant`, `element`, `ascii_char`, `lowercase_char`), combinators (`map`, `filter`, `bind`, `one_of`, `frequency`), collections (`list`, `list_of_size`, `option`, `tuple2`/`tuple3`, `string`, `lowercase_string`). Integrated shrinking: each generator produces a shrink tree so `bind` automatically propagates shrinking through dependent generators (Hedgehog RNG-replay trick). `Check.all(gen, prop)` / `Check.all_with(gen, prop, config)` run a property 100 times (configurable), shrink via DFS on failure, and panic with a formatted counterexample + reproducible seed. Properties may `return Bool`, use `assert`, or crash — the `__try_call` builtin catches `Assert_failure`/`Match_failure`/`Eval_error`/`Division_by_zero`/etc. and reports the crash as a shrinkable failure. Seed sources (highest priority first): `CheckConfig.seed`, `MARCH_PROP_SEED` env var, Unix time. CLI flag wired: `march test --seed=N` and `forge test --seed=N` both set `MARCH_PROP_SEED`. 14 tests in `test/stdlib/test_gen.march` + 11 tests in `test/stdlib/test_check.march`. Known compiler quirks worked around in-library: (a) parser rejects `() -> T` / `Unit -> T` in ADT field types (used `Thunk(Bool -> a)` wrapper); (b) typechecker can't unify `Random.Rng` across modules (introduced local `GenRng` record alias); (c) typechecker rejects `() -> a` in function param positions (thunk primitive uses `Bool -> a` with wildcard discard). These are compiler issues worth fixing separately; the library works correctly around them today.
