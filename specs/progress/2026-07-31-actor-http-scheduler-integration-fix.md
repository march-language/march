- ✅ **Actor + HTTP scheduler integration fix** — `runtime/march_runtime.c`: two bugs fixed that caused actors to be silently ignored in compiled HTTP servers. (1) Background scheduler thread: `march_spawn()` now calls `march_ensure_sched_started()` which launches a background pthread running `march_sched_run()` alongside the kqueue/epoll HTTP event-loop threads; for non-HTTP programs `march_run_scheduler()` joins the background thread instead of running inline — no observable change for non-HTTP programs. (2) `actor_get_int` field offset: corrected from raw word index to `index + 4` (skipping the 4-word header: rc, tag+pad, $dispatch, $alive) so index 0 returns the first state field instead of rc=1.
