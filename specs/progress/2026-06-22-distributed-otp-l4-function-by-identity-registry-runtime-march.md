- ✅ **Distributed OTP — L4 function-by-identity registry (`runtime/march_remote_registry.{c,h}`, 2026-06-22)** — increment 3a: the one genuinely net-new runtime mechanism (the spec flagged `runtime/` had no function-by-identity registry). A mutex-guarded chained hash table keyed by a target's CAS `impl_hash` → its marshalling stub (`void *`), recording `sig_hash` for the admission check. `register` (idempotent on identity) / `lookup` / `sig_hash` / `has` / `count` / `init` / `shutdown`. Distinct from the HCR `march_dispatch` table (NAME_ID-indexed + versioned); this is identity-keyed for cross-node dispatch. Linked into compiled binaries at both `bin/main.ml` sites; CAS key auto-includes it (dir-glob). 7-group C unit test (`test/test_remote_registry.c`, in `dune runtest`); codegen 320 still green. **Next L4:** `remote_ref` lowering (sig_hash/impl_hash from CAS — Touchpoint 1), serializable-signature gate, compiler-emitted marshalling stubs + `@main` register calls + DCE pinning, then wire to the live net-kernel socket.
