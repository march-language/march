Config

Config module: layered application configuration with typed keys.

Every configuration value lives under a typed KEY. A key names a path ((ns, name) or (ns, section, name), all atoms) and carries a codec that fixes the value's type:

let port = Config.key(:myapp, :port, Config.int())         -- Key(Int)
let host = Config.key_in(:myapp, :db, :host, Config.string()) -- Key(String)
Config.put(port, 4000)
Config.get(port)                 -- => Some(4000)
Config.put(host, "localhost")
Config.get(host)                 -- => Some("localhost")

Storage is heterogeneous (an Int port and a String host share one table), but a read can never hand back a value at the wrong type. Two things guarantee that:

  • statically, put(key : Key(v), value : v) and `get(key : Key(v)) :
  Option(v)` tie the value to the key's type, so storing an Int through
  `port` and using the result of `get(port)` as a Pid is a type error;
* at runtime, each value is stored as a tagged `Config.Value` and decoded
  by the READING key's codec. Two keys minted for the same path with
  different codecs (`key(:a, :b, int())` and `key(:a, :b, string())`)
  therefore disagree safely: the read is `None` from `get` and
  `Err(KeyWrongType(...))` from `fetch`, never an unchecked value.

Built-in codecs: int(), float(), string(), bool(), atom(), list(codec). Custom types: Config.codec(name, encode, decode), mapping onto Value.

Load from environment at startup: Config.from_env(Config.key(:myapp, :secret, Config.string()), "SECRET_KEY_BASE", "") Config.from_env_int(port, "PORT", 4000)

Validate values: Config.validate(port, fn p -> p > 0 && p < 65536)

Detect current environment (reads MARCH_ENV): Config.env() -- :dev | :test | :prod

Endpoint config shorthand (for web servers): Config.put_endpoint(4000, "localhost", my_secret) Config.endpoint_port(4000) Config.endpoint_host("localhost") Config.secret_key_base()

Named stores (for isolation in tests): let store = Config.new_store("my_test_store") Config.store_put(store, port, 4000) Config.store_get(store, port)

Types

typeValueValue = CfgInt(Int) | CfgFloat(Float) | CfgString(String)#

A stored configuration value. This closed, tagged sum is what the config table actually holds, which is what makes a heterogeneous table safe to read: a key's codec decodes a Value back to its own type and rejects any other tag.

typeCodecCodec(v) = Codec(String, v -> Value, Value -> Option(v))#

How a key's values are stored and read back: a type name (used in error messages), an encoder into Value, and a decoder that returns None for a Value of any other shape. Build one with int(), float(), string(), bool(), atom(), list(codec), or codec(name, encode, decode).

typeKeyKey(v) = Key(String, Codec(v))#

A typed configuration key: a path plus the codec fixing its value type.

typeErrorError = KeyMissing(String) | KeyWrongType(String, String, String)#

Why a typed read produced no value. KeyMissing(path) means nothing is stored under the path; KeyWrongType(path, expected, found) means a value is stored there, but it was written through a key of another type.

fncodeccodec(name : String, encode : v -> Value, decode : Value -> Option(v)) : Codec(v)#

A custom codec: store a v as a Value and read it back. name appears in KeyWrongType errors. Because Value is a closed sum, any codec that typechecks is safe; a decoder can only produce a v it can build from a Value.

type Mode = Fast | Safe

fn encode_mode(m : Mode) : Config.Value do
  match m do
    Fast -> CfgAtom(:fast)
    Safe -> CfgAtom(:safe)
  end
end

fn decode_mode(d : Config.Value) : Option(Mode) do
  match d do
    CfgAtom(:fast) -> Some(Fast)
    CfgAtom(:safe) -> Some(Safe)
    _              -> None
  end
end

let mode = Config.key(:myapp, :mode, Config.codec("Mode", encode_mode, decode_mode))

fnfetchfetch(k : Key(v)) : Result(v, Error)#

Look up key, returning Ok(value), Err(KeyMissing(path)), or Err(KeyWrongType(path, expected, found)), where expected is the reading codec's type name and found the stored value's (value_type_name). Reading the :test/:port Int stored in the example below through a String key gives Err(KeyWrongType(":test/:port", "String", "Int")).

Examples

march> let k = Config.key(:test, :port, Config.int())

march> let k = Config.key(:test, :port, Config.int())
march> let port = Config.key(:myapp, :port, Config.int())
march> Config.put(k, 8080)
march> let k = Config.key(:test, :port, Config.int())
march> let port = Config.key(:myapp, :port, Config.int())
march> Result.unwrap_or(Config.fetch(k), 0)
8080
march> let port = Config.key(:myapp, :port, Config.int())

fnfrom_envfrom_env(k : Key(String), env_var : String, default_val : String) : String#

Load a String value from an environment variable and store it under key. Uses default_val if the env var is not set (a set-but-empty variable stores ""). Always stores, overwriting any previous value; returns the value stored.

Examples

march> Config.from_env(secret, "MARCH_DOCTEST_NEVER_SET", "dev-secret")
"dev-secret"
march> let secret = Config.key(:myapp, :secret, Config.string())
march> Config.get_with_default(secret, "")
"dev-secret"
fnfrom_env_boolfrom_env_bool(k : Key(Bool), env_var : String, default_val : Bool) : Bool#

Load a Bool value from an environment variable and store it under key. Exactly "true", "1" and "yes" (case-sensitive) are parsed as true; any other value that is set (including "TRUE" or "") stores false. Uses default_val only when the variable is absent. Returns the value stored.

Examples

march> Config.from_env_bool(Config.key(:myapp, :verbose, Config.bool()), "MARCH_DOCTEST_NEVER_SET", true)

fnnew_storenew_store(name : String) : Vault(Value)#

Create (or reopen) an isolated named config store. Useful for testing or multi-tenant configurations. Returns a store handle holding tagged Values; use it with store_put, store_get and store_fetch and the same typed keys as the global table. Calling it again with the same name returns the same store, contents included.

Examples

march> let port = Config.key(:myapp, :port, Config.int())
march> let k = Config.key(:myapp, :port, Config.int())
march> let store = Config.new_store("new_store_demo")
march> Config.store_put(store, k, 1)
march> let k = Config.key(:myapp, :port, Config.int())
march> let port = Config.key(:myapp, :port, Config.int())
march> Option.unwrap_or(Config.store_get(Config.new_store("new_store_demo"), k), 0)
1
