Udp

UDP datagram sockets, built for packet rate.

Every send and receive moves a BATCH of datagrams per kernel crossing: on Linux recvmmsg/sendmmsg plus UDP GSO (up to 64 equal-sized datagrams per transit) and opt-in GRO; elsewhere a nonblocking drain loop. Waits park the green thread, never an OS thread, so one scheduler thread can serve many sockets. For more than one core's worth of packets, open open_sharded sockets (SO_REUSEPORT) and give each its own task.

"Reliable" here means the socket layer never loses data on its own: sends wait for buffer space instead of dropping, and stats reports the datagrams the KERNEL dropped for lack of receive-buffer room, so a receiver that falls behind knows it. UDP itself still delivers each datagram at most once, in any order, or not at all.

Packets are binary-safe Strings. An UdpAddr is an opaque, comparable address value: get one from resolve, local_addr or a received datagram.

typeUdpOptionsUdpOptions = {#

UdpSocket options for open_with.

  • reuse_addr, reuse_port: SO_REUSEADDR / SO_REUSEPORT. reuse_port
lets several sockets bind one port; Linux spreads flows across them.
  • broadcast: allow sending to a broadcast address.
  • gso: batch equal-sized sends into one kernel transit (Linux; turned
off automatically if the kernel or NIC refuses it).
  • gro: let the kernel coalesce a flow's received datagrams (Linux).
Datagrams still come back one by one; fewer syscalls deliver them.
  • recv_buffer, send_buffer: requested socket buffer bytes (0 keeps
the OS default). Linux caps them at net.core.rmem_max / wmem_max unless
the process has CAP_NET_ADMIN; raise those sysctls for real receive
headroom, since a full receive buffer is where UDP loses packets.
typeUdpStatsUdpStats = { rx_dropped: Int, tx_stalls: Int }#

Counters for a socket. rx_dropped is the kernel's count of datagrams dropped because the receive buffer was full, as of the last receive (Linux; -1 where the platform does not report it). tx_stalls counts the times a send had to wait for buffer space instead of dropping.

fnopen_shardedopen_sharded(host : String, port : {Int | _ >= 0 else "a port is at least 0" && _ <= 65535 else "a port is at most 65535"}, n : {Int | _ > 0 else "open at least one shard"},#

Open n sockets on one port with SO_REUSEPORT, one per receiving task. Linux hashes each flow to one socket, so n tasks each draining their own socket scale across cores. Port 0 picks a free port for the first and binds the rest to it. On failure every socket opened so far is closed.

Examples

let? socks = Udp.open_sharded("0.0.0.0", 9000, 4, Udp.defaults())

fnrecvrecv(sock : UdpSocket, max_size : {Int | _ > 0 else "max_size must be positive" && _ <= 65535 else "a datagram is at most 65535 bytes"}, timeout_ms : Int) : Result(Option((UdpAddr, String)), UdpError)#

Receive one datagram; Ok(None) if none arrives within timeout_ms. Prefer recv_batch for volume.

fnrecv_batchrecv_batch(sock : UdpSocket, max_msgs : {Int | _ > 0 else "receive at least one datagram" && _ <= 1024 else "at most 1024 datagrams per batch"},#

Receive up to max_msgs datagrams, in arrival order, each as (from, payload). Whatever is already queued comes back at once; otherwise the task parks until data arrives or timeout_ms passes (0: do not wait; negative: wait for ever). A timeout is Ok([]). A payload longer than max_size is truncated to it; 65535 never truncates.

Examples

match Udp.recv_batch(sock, 256, 2048, 100) do
  Ok(dgrams) -> List.map(dgrams, handle)
  Err(e)     -> println(Udp.error_message(e))
end
