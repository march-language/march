Js.Canvas

Canvas — 2D drawing bindings for March compiled with --target js.

Wraps the browser's CanvasRenderingContext2D. Requires --target js; calling these functions from a native build panics.

Usage: match Js.Dom.find("game-canvas") do None -> () Some(node) -> match Js.Canvas.get_context(node) do None -> () Some(ctx) -> Js.Canvas.set_fill_style(ctx, "#e74c3c") Js.Canvas.fill_rect(ctx, 10.0, 10.0, 80.0, 40.0) end end
