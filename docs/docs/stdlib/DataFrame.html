DataFrame

DataFrame module: columnar, lazy-evaluated tabular data.

Design: typed columns (IntCol/FloatCol/StrCol/BoolCol + nullable variants), a LazyFrame / Plan ADT for deferred execution, and a ColExpr language for vectorized filter predicates (no row materialization).

Phase 1 : types, construction, column/row access, structural ops Phase 2 : CSV and JSON I/O Phase 3 : ColExpr, LazyFrame, Plan interpreter Phase 4 : GroupBy + aggregation (uses Stats module) Phase 5 : inner_join, left_join, right_join, outer_join Phase 6 : describe, value_counts, col_z_score, col_normalize

Types

typeValueValue =#

Value: used at row boundaries only (from_rows / to_rows / with_column). Int/Float columns are backed by NativeArray (flat, contiguous storage); String/Bool columns by TypedArray. Sum/Mean aggregation reads the NativeArray directly (native_int_arr_sum/native_float_arr_sum — the same primitives auto-vectorize in --compile builds; see stdlib/native_array.march). Most other per-column operations (column-column arithmetic, ColExpr Add/Sub/Mul/Div, fill_null) still round-trip through List(Value)/List(Float) rather than staying in NativeArray form throughout — correct, just not yet on the fast path; see specs/optimizations.md P10 for the current state.

typeColumnColumn =#

Column: typed columnar storage. Each variant holds (name, data [, null_bitmap]). Data is stored as a contiguous TypedArray for O(1) random access and cache efficiency. Null bitmap: parallel TypedArray(Bool) where true = that row is null.

typeRowRow = Row(List((String, Value)))#

Row: a snapshot of one row, as an ordered assoc list. Slow path only.

typeDataFrameDataFrame = DataFrame(List(Column))#

DataFrame: an ordered list of equal-length typed columns.

typeColumnBuilderColumnBuilder =#

Internal builder: accumulates values during row-by-row construction.

typeColExprColExpr =#

ColExpr: a typed expression evaluated against a DataFrame column-by-column. Used for filter predicates. Evaluation is vectorized - no Row materialization.

typeSortDirSortDir = Asc | Desc#
typeJoinKindJoinKind = Inner | Left | Right | Outer#
typePlanPlan =#
typeLazyFrameLazyFrame = LazyFrame(Plan)#
typeCsvWriteOptsCsvWriteOpts = CsvWriteOpts(String, String, Bool)#
typeAggExprAggExpr =#

Aggregation expression for use with GroupedFrame.agg.

typeGroupKeyGroupKey = GroupKey(List(Value))#

Structural group key: a list of typed Values, one per group column.

typeGroupedFrameGroupedFrame = GroupedFrame(DataFrame, List(String))#

WindowExpr: window function expressions applied over an entire DataFrame (no partitioning in Phase 9; partitioned windows are a future extension).

fnadd_columnadd_column(df : DataFrame, col : Column) : Result(DataFrame, String)#

Appends a column at the end. Errors if a column with that name already exists, or if the frame has rows and the column's length differs. A frame with zero rows (including one with no columns) accepts a column of any length.

fnaggagg(gf : GroupedFrame, exprs : List(AggExpr)) : Result(DataFrame, String)#

Aggregates a GroupedFrame: one output row per distinct key, holding the group columns followed by one column per expression. Group (row) order is unspecified (it follows the internal hash map). Err if a group column is missing; an empty frame gives the empty frame, and an empty group_cols list puts every row in one group.

  • Count gives an Int; CountDistinct(c) an Int (null is one value);
`First(c)`/`Last(c)` keep the column's values.
  • Sum, Mean, Min, Max, Median, Std, Variance give Floats
(also for Int columns). `Std` and `Variance` are sample statistics
(n - 1); `Variance` of one row is 0.0 and `Std` of one row is null.
  • An aggregate over a missing, non-numeric or nullable column is null.
Output columns are rebuilt with widening inference, so such nulls read
back as the column type's default (e.g. 0.0) unless every group is
null.

Output names: the source column ("count" for Count), or the alias of AggAs(expr, name). When that name is already taken by a group column or an earlier output, a suffix is added: _sum, _mean, _min, _max, _count, _n_distinct, _std, _variance, _first, _last, _median (or _ plus the alias for AggAs).

Examples

DataFrame.group_by(sales, ["region"])
  |> DataFrame.agg([DataFrame.Count,
                    DataFrame.Sum("amount"),
                    DataFrame.AggAs(DataFrame.Mean("amount"), "avg")])
-- Ok(columns: region, count, amount, avg; one row per region)

fnbuilder_push_strictbuilder_push_strict(b : ColumnBuilder, val : Value) : Result(ColumnBuilder, String)#

Push val into builder b without type conversion (used by from_rows). Returns Err when val's type differs from the builder's, when a NullVal arrives in a typed builder, or when a non-null value arrives in a builder that has only seen nulls (nullable inference is not supported in strict mode).

fnbuilder_push_widenbuilder_push_widen(b : ColumnBuilder, val : Value) : ColumnBuilder#

Push val into builder b, widening the builder's type when needed (used by the CSV/JSON readers, group_by, joins, with_column and friends). Widening order is Bool < Int < Float < String: e.g. a Float arriving in an Int builder converts the earlier Ints to Float, and a String arriving in a numeric builder stringifies the earlier values. A Bool after Int or Float widens to String; Int/Float after Bool converts the Bools to 1/0.

Nulls are not preserved once a type is known: a NullVal pushed into a typed builder stores the type's default (0, 0.0, false; a String builder stores ""), and nulls seen before the first typed value are backfilled with that default.

fnbuilder_to_columnbuilder_to_column(b : ColumnBuilder) : Column#

Finalize a builder into a non-nullable column of its type, in push order. A builder that only ever saw nulls becomes an all-null NullableStrCol.

fncol_native_min_maxcol_native_min_max(df : DataFrame, name : String) : Result((Float, Float), String)#

Min and max of an IntCol/FloatCol, computed directly over the column's NativeArray via native_{float,int}_arr_min/max (tight vectorizable C loops, see runtime/march_runtime.c) instead of materializing a List(Float) and folding, as float_list-based callers do. An earlier version of this helper used a March-level recursive index loop over native__arr_get, which looked allocation-free but wasn't: get()'s Float/Int return value is boxed at each call site under the generic call convention, so it paid the same O(n) boxing cost as float_list — the true fix has to stay inside a single C-level reduction, exactly like col_native_sum's native__arr_sum. Err on an empty column (matches Stats.min_safe/max_safe on Nil).

fncol_native_momentscol_native_moments(df : DataFrame, name : String) : Result((Int, Float), String)#

(count, ssd) of an IntCol/FloatCol, where ssd is the sum of squared deviations from the mean; (0, 0.0) for an empty column, Err for a missing or non-numeric (including nullable) column. Computed via two native C-level reduction passes (native__arr_sum for the mean, then native__arr_sumsq_dev(arr, mean) for the deviations) instead of materializing a List(Float) and folding; see col_native_min_max's doc for why a March-level index loop can't do this allocation-free. This is the standard two-pass variance algorithm rather than Stats' single-pass Welford, so results may differ in the last bit or two but are equally stable (no catastrophic cancellation) for any realistic column. Sample variance is ssd / (count - 1); sample std dev is its square root.

fncol_native_sumcol_native_sum(df : DataFrame, name : String) : Result((Float, Int), String)#

Sum and element count of an IntCol/FloatCol, computed directly over the column's NativeArray (native_int_arr_sum/native_float_arr_sum — already vectorized in compiled builds) instead of materializing a List(Float) and folding, as float_list-based callers do. Sum(0.0) on an empty column matches Stats.sum's fold_left-over-Nil behavior.

fncol_normalizecol_normalize(col : Column) : Result(Column, String)#

Min-max normalize an IntCol or FloatCol to [0, 1]: (x - min) / (max - min). Returns a FloatCol of the same name; a column whose values are all equal gives all 0.0. Err for any other column type, including nullable numeric columns.

A zero-row column returns a zero-row FloatCol, for the same reason as col_z_score above: it is the n = 0 instance of the zero-range case below.

Examples

DataFrame.col_normalize(DataFrame.IntCol("x", native_int_arr_from_list([10, 15, 20])))
-- Ok(FloatCol("x", [0.0, 0.5, 1.0]))

fncol_z_scorecol_z_score(col : Column) : Result(Column, String)#

Z-score normalize an IntCol or FloatCol: (x - mean) / std with the sample standard deviation. Returns a FloatCol of the same name; a column whose values are all equal gives all 0.0. Err for any other column type, including nullable numeric columns.

A zero-row column returns a zero-row FloatCol rather than an error: it is the n = 0 instance of the zero-variance case just below, which already returns a same-length all-zeros column, and head(df, 0) or a filter that matches nothing produces one in ordinary use. The guard is on the list actually passed to Stats.*, which declare {List(Float) | len(_) > 0} and panic otherwise.

Examples

DataFrame.col_z_score(DataFrame.IntCol("x", native_int_arr_from_list([1, 2, 3])))
-- Ok(FloatCol("x", [-1.0, 0.0, 1.0]))

fneval_col_expreval_col_expr(df : DataFrame, expr : ColExpr) : Result(Column, String)#

Evaluate a ColExpr against a DataFrame, producing a typed Column with one entry per row. Literals are broadcast to the frame's row count.

  • Comparisons (Eq, Lt, ...) use compare_values and give a BoolCol
(so Int and Float compare numerically, and nulls are smallest).
  • And/Or/Not need (non-nullable) Bool operands, else Err.
  • Add/Sub/Mul give an IntCol, or a FloatCol if either side has a
Float; `Div` always gives a FloatCol (Int division is not truncated).
Null or non-numeric operands count as 0 (as 1 for a `Div` divisor).
  • StrContains/StrStartsWith/StrEndsWith need a (non-nullable)
String column, else `Err`.
  • IsNull/IsNotNull read the null bitmap; a non-nullable column has
no nulls.

Err when a referenced column is missing.

fneval_planeval_plan(plan : Plan) : Result(DataFrame, String)#

Interpret a Plan tree bottom-up, returning the first error any node produces. Limit/Offset use head/drop_rows, Select uses select_columns, Rename uses rename_column, DropCols ignores missing names, and Join evaluates both sides then calls apply_join.

fnfill_nullfill_null(col : Column, fill_val : Value) : Result(Column, String)#

Replace the nulls of a nullable column with fill_val, returning the NON-nullable column of the same type and name. The value must match the column type (an IntVal is also accepted for a Float column). Errors on a type mismatch, and on a non-nullable column (even though it has nothing to fill).

Examples

-- Ok(FloatCol("score", ...)) with every null replaced by 0.0

fnfill_null_forwardfill_null_forward(col : Column) : Column#
